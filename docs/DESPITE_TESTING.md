# Ðespiтe Tater 0.2.1 — проверка

Дата: 18 ноября 2026. База TClient: `087d4ae5ab7266f3afc4fe6d46a579eff83234f6`.

## Сборка

Windows x64, MSVC 19.51, CMake 4.3, Rust 1.96.1, Python 3.12.
Конфигурация **Release**, `AUTOUPDATE=OFF`, `VULKAN=OFF`, `VIDEORECORDER=OFF`.
Собраны `game-client`, `game-server` и `testrunner`.
В исходной базе остаются предупреждения MSVC о GNU-атрибутах и преобразовании
double/float в `time_test.cpp`; сборка не заявляется полностью без предупреждений.

## Автоматические проверки

- 19 тестов `DespiteAntiping.*`, `DespiteBlend.*`, `DespiteButton.*`: пройдены. Проверены стабильные 80 мс,
  реакция на вариацию, возврат к обычному режиму, независимость от числа кадров,
  смена соединения/перемотка тиков, пределы значений, пресеты и конфликты настроек.
  Новые проверки дополнительно подтверждают мягкую сходимость веса предсказания,
  одинаковый результат при 60 и 240 FPS, отсутствие перелётов, сброс после
  телепортации и немедленный переход к целевому весу при отключении фильтра.
- TDD: до реализации фильтра 5 из 6 добавленных тестов завершались ожидаемой
  ошибкой поведения, после реализации прошли все 14 тестов двух наборов.
- Анимация кнопок: 5 тестов проверяют постепенное увеличение/возврат,
  смену направления при повторном наведении, одинаковое время при 60/240 FPS,
  продавливание/отпускание и защиту от некорректного времени кадра.
  До реализации 4 из 5 тестов ожидаемо падали; после реализации проходят все.
- Полный `run_tests`: **392 из 393 C++-тестов пройден**, 3 теста исходной базы
  отключены upstream. `Net.Ipv4AndIpv6Work` не получил UDP-пакет через IPv6 localhost
  (`net_test.cpp:48–49`, таймаут 10 секунд).
- Отдельная проверка стандартными Python-сокетами воспроизвела проблему среды:
  `127.0.0.1` доставляет пакет, `::1` завершается таймаутом. Настройки сети ОС
  не менялись. Падающий тест не удалён и не исключён из набора.
- Rust workspace targets и 18 Rust doc-тестов: пройдены.
- `check_header_guards.py`, `check_config_variables.py`,
  `tidy_alphabetical.py --dry-run`, clang-format для новых файлов и
  `git diff --check`: пройдены.
- Независимое ревью: исправлены скрытие страницы восстановления вкладок,
  применение параметров при смене профиля и пересечение HUD со status bar.
  Для версии 0.2.0 отдельно проверены связь фильтра с игровыми тиками, отдельное
  состояние соединений, сбросы и геометрия меню 4:3/16:9; новых замечаний нет.
  В 0.2.1 проверены постоянные области клика, отдельное состояние кнопок,
  интервалы и возврат анимации. Замечание об обрезании увеличенной кнопки
  исправлено внутренними отступами панели по 4 UI-единицы.
- Исправлена линковка новых Rust Windows runtime: добавлена `synchronization.lib`
  для функций WaitOnAddress/WakeByAddress, отсутствовавшая в унаследованном списке.

## Ограничения проверки

Ранее Release-клиент 0.2.0 был запущен из отдельного дистрибутива `DespiteTater.exe`;
заголовок окна — «Ðespiтe Tater». Журнал подтверждает загрузку русского перевода
и инициализацию OpenGL. Захват окна дважды завершился ошибками
`FrameArrived timed out` / `window capture timed out`; дальнейшее управление
остановлено пользователем через Escape. Визуальная проверка не считается
завершённой. Референс использован как тема, а не как список иных клиентов.
В 0.2.1 анимация проверена тестами и сборкой; новый визуальный прогон не проводился.

Предсказание не меняет реальную сетевую задержку. Утверждение «80 мс ощущаются как
40 мс» не измерялось и не гарантируется. Нужны игровые сравнения на удалённом
сервере, в том числе с jitter, потерями пакетов, freeze, hook и dummy.

Основной workflow проекта — `despite.yml`: Windows Release, сборка клиента,
полный набор тестов и загружаемый артефакт. Унаследованные workflow TClient
оставлены для ручного запуска, чтобы они не дублировали сборки проекта и не
публиковали исходные TClient-релизы автоматически.
